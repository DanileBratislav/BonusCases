# BonusCases

Кейсы с колесом призов за нарты для Paper 1.21.x.

## Сборка

Нужны Java 21 и Maven.

```sh
mvn clean package
```

Готовый файл: `target/BonusCases-1.0.0.jar`. Положите его в `plugins/` и перезапустите сервер (не `/reload`). Если на сервере другая версия 1.21.x, поменяйте `paper-api` в `pom.xml` на свою.

## Как пользоваться

1. Наведитесь на блок и введите `/bonuscase <цена> <номер>`:
   - `/bonuscase 15 1` — первый кейс, 15 нартов
   - `/bonuscase 30 2` — второй кейс, 30 нартов
   - `/bonuscase 50 3` — третий кейс, 50 нартов
   Номер — это набор наград (у каждого номера свои награды), цена — стоимость на этом блоке. Повторная команда на том же блоке обновляет цену и номер.
2. `/bonuscase edit <номер>` — откройте редактор и положите предметы, которые должны выпадать.
   - Количество в стаке = количество в награде.
   - Shift+ЛКМ / Shift+ПКМ — вес +1 / -1, Q / Ctrl+Q — +10 / -10. Чем больше вес, тем чаще выпадает.
   - Убрать награду: возьмите её на курсор и кликните по корзине (справа внизу).
   - Сохраняется при закрытии окна.
3. Игроки: ПКМ по блоку — меню «Открыть / Что внутри», ЛКМ — сразу список наград с шансами. После оплаты открывается колесо: подсветка бежит по кругу, замедляется и останавливается на призе.

Остальные команды: `/bonuscase remove` (смотреть на блок), `/bonuscase list`, `/bonuscase reload`.

## Права

- `bonuscase.admin` — команды (по умолчанию op)
- `bonuscase.use` — открывать кейсы (по умолчанию все)

## Нарты

По умолчанию списание идёт через Vault (CMI его поддерживает). Если нарты — отдельная валюта, в `config.yml` переключите `economy.mode: command` и укажите плейсхолдер баланса и команды списания.

## Файлы

- `config.yml` — сообщения, названия кейсов, валюта, объявление редких призов
- `cases.yml` — привязанные блоки
- `loot.yml` — награды
